Computer Systems Depot - Embeddable Form Examples

Use these code snippets to embed the Computer Systems Depot intake form on any website:

Option 1: Simple iframe (Copy and paste this HTML)

<iframe 
    src="https://your-replit-app.repl.co/embed?source=website_embed" 
    width="100%" 
    height="800" 
    frameborder="0" 
    style="border: none; border-radius: 8px;"
    title="Computer Systems Depot Intake Form">
</iframe>

Option 2: Smart widget with auto-resize (Recommended)

<div id="csd-intake-widget"></div>
<script>
(function() {
    var config = {
        baseUrl: 'https://your-replit-app.repl.co',
        source: 'website_widget',
        campaign: '', // Optional campaign tracking
        width: '100%',
        height: '800px'
    };
    
    // Create iframe
    var iframe = document.createElement('iframe');
    iframe.src = config.baseUrl + '/embed' + 
        '?source=' + encodeURIComponent(config.source) +
        (config.campaign ? '&campaign=' + encodeURIComponent(config.campaign) : '');
    iframe.width = config.width;
    iframe.height = config.height;
    iframe.frameBorder = '0';
    iframe.style.border = 'none';
    iframe.style.borderRadius = '8px';
    iframe.style.display = 'block';
    iframe.title = 'Computer Systems Depot Intake Form';
    
    // Auto-resize functionality
    window.addEventListener('message', function(event) {
        if (event.data && event.data.type === 'csd-iframe-resize') {
            iframe.height = event.data.height + 'px';
        }
        
        if (event.data && event.data.type === 'csd-form-success') {
            // Form submitted successfully
            console.log('CSD Form submitted successfully:', event.data.data);
            // You can add custom success handling here
        }
    });
    
    // Insert into page
    var container = document.getElementById('csd-intake-widget');
    if (container) {
        container.appendChild(iframe);
    }
})();
</script>

URL Parameters for Tracking

Add these parameters to track sources and campaigns:

  • ?source=phone_call - Track where leads came from
  • &campaign=google_ads - Track marketing campaigns
  • &call_id=12345 - Tie form to phone system records

Example URLs:

  • https://computersystemsdepot.com/start-service
  • https://computersystemsdepot.com/start-service?source=phone_call&call_id=12345

Setup Instructions:

  1. Replace https://your-replit-app.repl.co with your actual Replit app URL
  2. Customize the source parameter to track different placements
  3. Add campaign parameters for marketing attribution
