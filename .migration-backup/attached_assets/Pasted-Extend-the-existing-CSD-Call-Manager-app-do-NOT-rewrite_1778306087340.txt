Extend the existing CSD Call Manager app (do NOT rewrite it). Add advanced call routing, business hours, configurable IVR, and analytics.

NEW DATABASE TABLES:

Table: business_hours
  - id (uuid)
  - day_of_week (0–6, 0=Sunday)
  - open_time (time, nullable — null means closed all day)
  - close_time (time, nullable)
  - timezone (text, default 'America/New_York')

Table: holidays
  - id (uuid)
  - date (date)
  - label (text)
  - closed (boolean, default true)

Table: ivr_menus
  - id (uuid)
  - name (text) — e.g. 'main', 'after_hours', 'repair_submenu'
  - greeting_text (text) — text-to-speech greeting
  - greeting_audio_url (text, nullable) — optional pre-recorded audio
  - timeout_seconds (integer, default 7)
  - is_default (boolean) — only one true per business_hours_state
  - business_hours_state (enum: 'open', 'closed', 'either')

Table: ivr_options
  - id (uuid)
  - menu_id (uuid, FK ivr_menus.id)
  - digit (text, '0'–'9', '*', '#')
  - label (text) — human description
  - action (enum: 'forward', 'voicemail', 'submenu', 'queue', 'hangup')
  - target (text) — phone number, menu_id, or queue_id depending on action

Table: call_queues
  - id (uuid)
  - name (text)
  - strategy (enum: 'ring_all', 'round_robin', 'least_recent') default 'ring_all'
  - max_wait_seconds (integer, default 60)
  - on_timeout_action (enum: 'voicemail', 'forward')
  - on_timeout_target (text)

Table: queue_members
  - queue_id (uuid)
  - user_id (uuid)
  - priority (integer, default 0)
  - PK (queue_id, user_id)

Table: voicemails
  - id (uuid)
  - call_id (uuid, FK calls.id)
  - recording_url (text)
  - transcription (text, nullable)
  - duration_seconds (integer)
  - is_listened (boolean, default false)
  - listened_at (timestamptz, nullable)
  - listened_by (uuid, FK users.id, nullable)

UPDATED WEBHOOK LOGIC:
- /webhooks/voice/incoming now checks business_hours + holidays first.
  - If outside business hours: route to the 'closed' default IVR menu (typically: brief greeting → voicemail).
  - If inside business hours: route to the 'open' default IVR menu.
- IVR menus and options are loaded from the database, not hardcoded.
- Submenus supported: pressing a digit can lead to another menu.
- Queue action: dials all members of a queue per their strategy. Track which user answered in calls.assigned_to_user_id.
- Voicemail action: plays prompt, records up to 180s, saves to voicemails table; transcription via Twilio's <Record transcribe="true"/>.

NEW FRONTEND PAGES:
- /admin/hours   — owner-only: edit weekly business hours and holidays
- /admin/ivr     — owner-only: visual IVR builder (menus, options, drag-to-reorder digits, link options to actions)
- /admin/queues  — owner-only: create queues, add tech members, set strategy
- /voicemails    — list of voicemails with player, transcription preview, mark-as-listened, filter unlistened first
- /analytics     — analytics dashboard (see below)

ANALYTICS DASHBOARD (/analytics):
- Date range picker (default: last 30 days). Uses Recharts.
- KPI cards: total calls, answered %, missed %, avg duration, voicemails received, outbound calls placed.
- Charts:
  - Calls per day (stacked: inbound answered / inbound missed / outbound)
  - Calls by hour-of-day heatmap (which hours are busiest)
  - IVR option distribution (pie/bar — which menu options callers pick most)
  - Top inbound numbers (table with caller, count, last call)
  - Tech performance (table): calls handled, avg duration, voicemails returned (owner-only view)
- Export current view as CSV.
