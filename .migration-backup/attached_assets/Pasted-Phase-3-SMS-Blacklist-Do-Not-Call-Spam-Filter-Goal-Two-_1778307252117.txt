Prompt to paste into Replit Agent
Extend the existing CSD Call Manager app. Add SMS messaging and call protection features. Do NOT modify existing voice/IVR/analytics functionality.

A2P 10DLC NOTE (read first):
- US SMS through Twilio requires A2P 10DLC brand + campaign registration. This must be done in the Twilio console before any SMS will deliver. The app should still build and work in dev; flag in the README that production SMS requires this registration to be complete.

NEW DATABASE TABLES:

Table: messages
  - id (uuid)
  - twilio_message_sid (text, unique)
  - direction (enum: 'inbound', 'outbound')
  - from_number (text, indexed)
  - to_number (text, indexed)
  - body (text)
  - status (enum: 'queued','sent','delivered','undelivered','failed','received')
  - error_code (text, nullable)
  - media_urls (text[], nullable) — MMS attachments
  - sent_by_user_id (uuid, FK users.id, nullable) — for outbound
  - thread_key (text, indexed) — normalized conversation partner number
  - related_call_id (uuid, FK calls.id, nullable) — link SMS to a call if in same thread
  - created_at (timestamptz)

Table: message_templates
  - id (uuid)
  - name (text)
  - body (text) — supports {{customer_name}}, {{ticket_number}} placeholders
  - created_by (uuid)
  - shared (boolean, default true)

Table: blacklist
  - id (uuid)
  - phone_number (text, unique, indexed)
  - reason (text, nullable)
  - blocks_calls (boolean, default true)
  - blocks_sms (boolean, default true)
  - added_by (uuid)
  - created_at (timestamptz)

Table: dnc_list  (Do Not Call — outbound suppression)
  - id (uuid)
  - phone_number (text, unique, indexed)
  - source (enum: 'manual','customer_request','national_dnc')
  - notes (text, nullable)
  - created_at (timestamptz)

Table: spam_scores  (cache of lookups)
  - phone_number (text, primary key)
  - score (integer, 0–100, higher = more likely spam)
  - sources (jsonb) — which lookups contributed
  - last_checked (timestamptz)

NEW WEBHOOK LOGIC (voice — augment, do not replace):
- Before routing an inbound call, check blacklist. If blocked, hang up immediately (return TwiML <Hangup/>) and log the call with status 'blocked'.
- Optional: check spam_scores cache; if score > threshold (configurable, default 70), send to a 'screen' IVR that requires the caller to press a digit before being connected.

NEW WEBHOOK ENDPOINTS:
- POST /webhooks/sms/incoming  — receive SMS, store, broadcast via SSE/WebSocket to logged-in users
- POST /webhooks/sms/status    — delivery status callbacks

NEW API ENDPOINTS:
- GET    /api/messages                     — list threads (grouped by thread_key)
- GET    /api/messages/thread/:thread_key  — full conversation
- POST   /api/messages                     — send SMS: { to_number, body, template_id?, media_urls? }
- GET    /api/templates / POST / PATCH / DELETE
- GET/POST/DELETE /api/blacklist
- GET/POST/DELETE /api/dnc
- POST   /api/spam/check                   — { phone_number } → returns score (uses Twilio Lookup v2 with 'line_type_intelligence' + optional third-party reputation)
- Outbound /api/calls/outbound and /api/messages must check DNC list before sending; reject with clear error if number is on DNC.

NEW FRONTEND PAGES:
- /messages           — threaded SMS view (left: list of conversations, right: selected thread with reply box, template picker)
- /admin/blacklist    — list/add/remove blocked numbers
- /admin/dnc          — list/add/remove DNC numbers, CSV import
- /admin/spam         — view recent spam checks, configure auto-screening threshold
- /admin/templates    — message template editor

UI:
- Real-time updates: when a new SMS arrives, the messages page updates without refresh (SSE is fine; WebSocket also fine — pick one).
- Template picker in the reply box; selecting a template fills the body with placeholders resolved against the conversation contact (if known).
