## 2. INFRASTRUCTURE & MESH OPERATIONAL CONFIGURATION
When generating or editing the MeshCentral `config.json` schema, you must strictly enforce the following network validation checklist:
* **No Section Disabling:** Ensure all active structural keys (`settings`, `domains`, `letsencrypt`) have NO leading underscores (`_`). They must be fully exposed to the JSON compiler.
* **Network Isolation Guard:** `WANonly` and `LANonly` are mutually exclusive. Since this architecture utilizes a public Let's Encrypt configuration via an external subdomain, `WANonly` must always be set to `true`, and `LANonly` must NEVER exist or be set to `true` inside the same file.
* **Port Syncing:** Keep the core port mappings bound explicitly to:
    * `port`: 443
    * `aliasPort`: 443
    * `redirPort`: 80
    * `redirAliasPort`: 80
* **Let's Encrypt Challenge Rule:** Always pass `"skipChallengeVerification": true` and `"production": true` to prevent validation loops during staging handshakes.
