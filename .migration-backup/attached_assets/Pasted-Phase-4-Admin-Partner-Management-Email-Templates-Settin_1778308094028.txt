Phase 4 — Admin, Partner Management, Email Templates, Settings
Goal: Make this a polished multi-user system: full user management, optional sub-account/partner structure, email notifications, and a real settings hub.
Prompt to paste into Replit Agent
Extend the existing CSD Call Manager app. Add admin/configuration features. No changes to voice, SMS, or analytics behavior.

NEW DATABASE TABLES:

Table: organizations  (multi-tenancy lite — for "partners" if owner ever resells)
  - id (uuid)
  - name (text)
  - parent_org_id (uuid, FK organizations.id, nullable)  — hierarchical
  - twilio_subaccount_sid (text, nullable)
  - settings (jsonb)
  - created_at (timestamptz)

Table: org_memberships
  - org_id (uuid)
  - user_id (uuid)
  - role (enum: 'owner','admin','tech','viewer')
  - PK (org_id, user_id)

Table: email_templates
  - id (uuid)
  - org_id (uuid)
  - name (text)
  - subject (text)
  - body_html (text)
  - body_text (text)
  - trigger (enum: 'manual','missed_call','voicemail_received','new_customer', etc.)

Table: notification_settings
  - user_id (uuid, primary key)
  - missed_call_email (boolean, default true)
  - missed_call_sms (boolean, default false)
  - voicemail_email (boolean, default true)
  - voicemail_sms (boolean, default false)
  - daily_digest_email (boolean, default false)
  - quiet_hours_start (time, nullable)
  - quiet_hours_end (time, nullable)

Table: invitations
  - id (uuid)
  - email (text)
  - org_id (uuid)
  - role (text)
  - invited_by (uuid)
  - token (text, unique, indexed)
  - expires_at (timestamptz)
  - accepted_at (timestamptz, nullable)

EMAIL PROVIDER:
- Use Resend (preferred) or SendGrid. Add RESEND_API_KEY to env.
- All transactional emails (invites, notifications, digests) go through this provider.
- Add unsubscribe link for digest emails (CAN-SPAM compliance).

NEW API ENDPOINTS:
- Full CRUD for organizations, org_memberships (owner of org only)
- POST /api/invitations  — invite by email; sends email with signup link
- POST /api/invitations/accept  — token-based acceptance flow
- CRUD for email_templates
- GET/PATCH /api/notification-settings (own settings)
- POST /api/notifications/test  — send a test email/SMS to verify settings
- POST /api/integrations/twilio/test  — verify Twilio creds work
- GET  /api/integrations/health  — overall system health (Twilio reachable, Supabase reachable, last webhook received timestamp, etc.)

NEW FRONTEND PAGES:
- /admin/users      — extend Phase 1 user mgmt: invite by email, deactivate, audit log of role changes
- /admin/partners   — owner-only: create child organizations, manage members per org
- /admin/email-templates — editor with live preview, placeholder reference, test-send button
- /settings/notifications — per-user notification preferences with test-send button
- /settings/integrations  — view Twilio account status, Supabase status, webhook last-seen timestamps; "test connection" buttons
- /settings/profile       — name, email, password, phone, time zone

NOTIFICATION DELIVERY:
- Background worker (use a simple in-process scheduler or Replit's always-on cron) that sends daily digest emails at user-specified time.
- Real-time triggers: missed call → email/SMS to assigned tech (if any) and owner; voicemail received → email with audio link.
- Respect quiet hours; queue and deliver at end of quiet window.
